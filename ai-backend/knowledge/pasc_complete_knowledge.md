## CONFERENCE SCHEDULE (February 13, 2026)

### Timeline
- **10:00 - 10:30 AM:** Registration (entering at the hub)
  - Attendees receive kit: name badges, lanyards, t-shirt handouts
  - Proceed to gym to hang out until registration closes
  
- **10:30 - 11:00 AM:** Welcome, Speakers, Keynote Speaker

- **11:00 AM onwards:** Split rotation
  - Half go to lunch, half go to workshops
  - 1-hour workshops, 2 rotations
  - Then groups switch

- **End of Day:** Closing keynote speaker, Color Olympics

### Workshop Information
- **Format:** Each presenter does their workshop TWICE
- **Room Naming:** Each breakout room is named after a planet
  - Sun, Venus, Neptune, Moon, Earth, Mercury, Saturn, Uranus, Mars, Jupiter
- **Navigation:** "Follow the spaceship to Saturn!" style directions
- **Topics:** Leadership, teamwork, discussion-based activities
- **Groups:** 2-3 people per presentation team

## THE WEBSITE'S TECHNICAL JOURNEY

### Phase 1: ColdFusion MVP (October 2025)
**Built in one weekend (~25 hours)**
- ColdFusion backend
- Microsoft SQL Server database
- Custom admin panel for content management
- ~2,300 lines of code across 22 files
- Deployed to DailyRazor hosting
- Live at: https://pascregionj.com

**Features Built:**
- Public pages: Home, About, Workshops, Registration, Gallery, Contact, Resources
- Admin panel with login, announcements, forms management, gallery uploads
- Embedded Google Forms for registration and workshop applications
- Responsive mobile design
- Space theme with purple/blue/pink colors

### Phase 2: Angular Conversion (November 2025)
- Converted frontend to Angular 17+ standalone components
- Maintained ColdFusion APIs for backend data
- Modern component-based architecture
- Improved animations and transitions
- Better mobile responsiveness

### Phase 3: React Conversion (November 2025)
**Completed in just 15 hours across 3 sessions!**
- Industry estimate for this work: 2-5 months, $15,000-50,000+
- Demonstrates rapid framework-to-framework migration
- All three versions (ColdFusion, Angular, React) share common ColdFusion APIs
- Proves the value of API-first architecture

### Phase 4: AI Integration (Current - November 2025)
- AI-powered chat assistant in bottom-right corner
- Voice input using OpenAI Whisper API
- GPT-4o-mini for intelligent responses
- Knowledge base for accurate answers
- Navigation actions (redirecting users to pages)
- Python FastAPI backend for AI services

### Development Approach
Rasti's methodology:
- "Perfect CLI prompts" - describe desired outcomes, let AI determine implementation
- Rapid iteration over extensive planning
- Build from existing working versions (Angular→React, not ColdFusion→React)
- Practical solutions over theoretical "proper" implementations
- AI tools as force multipliers, not replacements for expertise
